# Positivus

Positivus is a responsive digital marketing landing page built with HTML and CSS. The project presents a clean and modern interface for a digital marketing agency, including service offerings, case studies, and contact-focused sections.

## Features

- Responsive landing page
- Modern and clean UI
- Navigation bar
- Hero section
- Digital marketing services section
- Case studies section
- Call-to-action sections
- Contact/proposal section
- Responsive layouts for different screen sizes
- Custom CSS styling
- Google Font integration

## Sections

- Hero
- Services
  - Search Engine Optimization
  - Pay-per-Click Advertising
  - Social Media Marketing
  - Email Marketing
  - Content Creation
  - Analytics and Tracking
- Call to Action
- Case Studies
- Contact / Proposal

## Technologies

- HTML5
- CSS3
- Google Fonts
